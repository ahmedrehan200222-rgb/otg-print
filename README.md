# OTG Print

تطبيق أندرويد للطباعة على طابعة USB (مثل HP LaserJet P3005) عن طريق كابل OTG.

## بيعمل إيه
- يكتشف الطابعة ويطلب إذن USB.
- يحوّل أي PDF إلى PCL 5 raster (300 dpi) ويبعته للطابعة.
- يسجّل نفسه كـ **Print Service**، فالطابعة تظهر في قائمة Print في Word وChrome وأي تطبيق.

## البناء (بدون Android Studio)
1. ارفع المشروع على GitHub (فرع main).
2. افتح تبويب **Actions** ← **Build APK** ← انتظر ينتهي.
3. نزّل الـ artifact باسم `OtgPrint-debug-apk` وفك الضغط.

## التثبيت
- انسخ `app-debug.apk` للموبايل وثبّته، أو من PowerShell:
  `.\adb install -r app-debug.apk`

## الاستخدام
1. وصّل الطابعة بكابل OTG وشغّلها.
2. افتح التطبيق ← **اكتشاف الطابعة** ← وافق على الإذن.
3. جرّب **طباعة صفحة اختبار**.
4. لطباعة Word/أي تطبيق: فعّل الخدمة من الإعدادات ← الاتصال ← الطباعة (Printing) ← **OTG Print**.
   بعدها اختار Print من أي تطبيق والطابعة هتظهر.

## ملاحظات
- الصفحة A4 فقط حالياً، وأبيض/أسود.
- لو الطباعة طلعت مقصوصة أو مزاحة، عدّل ثوابت LEFT_OFFSET / LOGICAL_H في PclEncoder.kt.
